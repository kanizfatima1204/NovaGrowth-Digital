# NovaGrowth Digital Landing Page

## Project
Responsive conversion-focused landing page for a fictional digital service business.

## Objective
Generate consultation leads from website visitors.

## Technologies
- HTML5
- CSS3
- JavaScript
- Responsive Design

## Features
- Responsive navigation
- Hero section
- Services section
- Benefits section
- Testimonials / social proof
- Conversion-focused CTAs
- Lead generation form
- Responsive mobile layout
- Scroll reveal animations
- Mobile navigation menu
- Accessible form labels and status message

## Responsive Breakpoints
- Desktop
- Tablet
- Mobile

## How to Run
1. Extract the ZIP file.
2. Open the `nova-growth-landing` folder in VS Code.
3. Open `index.html` directly in a browser, or use the Live Server extension.
4. Test the layout at desktop, tablet, and mobile widths.

## Note
The lead form is a frontend demo. It displays a success message but does not send data to a backend.
